# TheEnd Support (локальный помощник проекта)

Это бесплатная консольная панель для контроля текущей работы TheEnd. Работает на Python из стандартной библиотеки, без API-ключа и без платных запросов.

## Запуск в Windows
1. Скачайте/клонируйте ветку `feature/theend-supervisor-mvp` репозитория.
2. Распакуйте папку проекта.
3. Дважды нажмите `START_THEEND_SUPPORT.bat`.

## Что умеет
- Показывает статусы задач и незакрытые критерии.
- Запускает локальный аудит проекта.
- Показывает ближайший конкретный шаг.
- Открывает PR и последнюю проверку GitHub.

## Ограничения
Это помощник контроля проекта, а не удалённый оператор компьютера и не игровой бот. Он не управляет LDPlayer/игрой, не хранит пароли и не подключается к аккаунтам. Пока облачная Android-сессия и сбор ресурсов не подтверждены, панель прямо показывает их как незавершённые.
